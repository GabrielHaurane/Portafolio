# Textos e i18n

Init en `src/i18n.js:6-16`: recursos `es`/`en`, `lng: 'es'`, `fallbackLng: 'es'`. Se carga una vez desde `main.jsx:4`. El cambio de idioma lo hace `LanguageSwitcher.jsx:7-10` (toggle es↔en, sin persistencia).

## Reglas

1. **Paridad exacta.** Toda clave que agregues/renombres/borres va en `src/locales/es/translation.json` **y** `src/locales/en/translation.json`. Hoy ambos tienen el mismo set de claves; mantenerlo.
2. **Consumo:** `const { t } = useTranslation();` en el componente que renderiza, o `t()` en la página y el texto pasa por props (patrón de `Proyectos.jsx:17-54` → `ProjectCard*`, y `Contacto.jsx:48-55` → `FormularioPosible`). Elegí uno por componente, no los dos para el mismo texto.
3. **Listas:** arrays JSON + `t("clave", { returnObjects: true })` y `.map` (`Proyectos.jsx:29`, `Home.jsx:19`).
4. **Claves nuevas: agrupadas por namespace en objeto anidado** (`gh_app.*`, `technologies_page.*`, `experience.*`, `menu.*`, `form.*`). Las claves planas numeradas (`project1_title`, `project2_features`…) son el formato viejo: no seguir numerando.
5. **No renombrar claves existentes "por prolijidad"**, aunque tengan typo: `title_projetcs` (`Proyectos.jsx:13`) funciona así.
6. **URLs que varían por idioma** van en locales (el CV: `menu.drive`, usado en `Menu.jsx:44,113`). URLs iguales en ambos idiomas (GitHub, demos) se quedan como props literales en el JSX (`Proyectos.jsx:21,31-32`).
7. **Atributos también son texto visible:** `alt`, `aria-label`, `title`. Hoy hay deuda: `alt="Tu Foto"` (`Menu.jsx:16,89`), `aria-label="Cargando imagen/video"` (`LoadingImage.jsx:8`, `LoadingIframe.jsx:8`), labels de `LanguageSwitcher.jsx:14`. No sumar más; si tocás esas líneas, traducilas.
8. Nombres propios (`GHProgrammingApp`, `SwaplyAr`, títulos de proyectos) igual van en ambos JSON aunque el valor sea idéntico — así lo hace el repo (`gh_app.title`, `project1_title`).
